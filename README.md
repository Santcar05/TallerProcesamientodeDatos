# Brechas Educativas y de Conectividad en Colombia
Proyecto analítico desarrollado para el curso Procesamiento de Datos a Gran Escala - Pontificia Universidad Javeriana.

## Descripción
Proyecto analítico para el curso Procesamiento de Datos a Gran Escala - Pontificia Universidad Javeriana.
Análisis territorial de la relación entre acceso a internet fijo y resultados de la prueba Saber 11 a nivel municipal en Colombia, usando Apache Spark y técnicas de aprendizaje de máquina.

## Contenido del repositorio
Proyecto_2_entrega.ipynb - Entendimiento del negocio, exploración y descripción de datos, modelado, regresión lineal y K-Means

## Fuentes de datos
-Dataset Internet Fijo Accesos por tecnología y segmento. Disponible en: https://www.datos.gov.co/Ciencia-Tecnolog-a-e-Innovaci-n/Internet-Fijo-Accesos-por-tecnolog-a-y-segmento/n48w-gutb/about_data
-Dataset Resultados únicos Saber 11. Disponible en: https://www.datos.gov.co/Educaci-n/Resultados-nicos-Saber-11/kgxf-xxbe/about_data
