# Brechas Educativas y de Conectividad en Colombia
Proyecto analítico desarrollado para el curso Procesamiento de Datos a Gran Escala - Pontificia Universidad Javeriana.
Descripción: Análisis territorial de la relación entre acceso a internet fijo y resultados de la prueba Saber 11 a nivel municipal en Colombia, usando Apache Spark y técnicas de aprendizaje de máquina.

Contenido del repositorio:
Proyecto_2_entrega.ipynb - Entendimiento del negocio, exploración y descripción de datos, modelado, regresión lineal y K-Means

Fuentes de datos:

Internet Fijo Accesos por tecnología y segmento - datos.gov.co
Resultados únicos Saber 11 - datos.gov.co

Integrantes: Santiago Castro, Juan Felipe Parrales, Juan Pablo Morales, Cristian Muñoz
